java.nio.channels.Selector

스레드 하나가 수천 개 연결을 지켜보는 구조

Selector는 I/O를 대신 해 주지 않습니다. OS에게 "이 소켓들 중 지금 막히지 않고 읽거나 쓸 수 있는 것"을 물어보고, 그 답을 SelectionKey 집합으로 돌려줄 뿐입니다. 실제 read()·write()는 이벤트 루프 스레드가 채널에 직접 호출합니다.

전체 구조

SelectionKey 한 개에 들어 있는 것

channel.register(selector, ops, attachment)가 돌려주는 키는 "이 채널을 이 Selector가 지켜본다"는 등록 정보 한 건입니다. 채널 하나를 Selector 여러 개에 등록하면 키도 여러 개 생깁니다.

누가 쓰나 · 등록channel()

지켜보는 채널. 반드시 configureBlocking(false) 상태여야 등록됩니다.

누가 쓰나 · 애플리케이션interestOps

"무엇이 준비되면 알려 줘". 바꾸면 updateKeys에 들어가 다음 select()에서 OS에 반영됩니다.

누가 쓰나 · SelectorreadyOps

지난 select()에서 확인된 준비 상태. isReadable() 등은 이 값을 읽습니다.

누가 쓰나 · 애플리케이션attachment

연결별 상태를 붙이는 자리. 읽기 버퍼·쓰기 큐를 여기에 두면 버퍼가 연결끼리 섞이지 않습니다.

selectedKeys에 없던 키가 준비되면

readyOps를 새 값으로 덮어쓰고 집합에 추가합니다.

이미 selectedKeys에 있는 키라면

readyOps에 새 비트를 OR로 더할 뿐, 지난번 비트를 지우지 않습니다. it.remove()를 빠뜨리면 지난번 isAcceptable()이 계속 참으로 남아, accept()가 null을 돌려주고 NPE로 이어집니다. 예제의 BadEchoServer는 select 2회 만에 멈췄습니다.

select() 한 바퀴 안에서 일어나는 일

JDK 11 이후 구현 기준입니다. 세부 메서드 이름은 OS별 구현체마다 조금씩 다릅니다.

  1. processUpdateQueue() · updateKeys 비우기

    다른 스레드나 이전 루프에서 바뀐 interestOps를 OS 관심 목록에 반영합니다.

  2. processDeregisterQueue() · cancelledKeys 비우기

    취소된 키를 OS에서 빼고 keys·selectedKeys에서 지웁니다. 채널을 닫아도 실제 해제는 여기서 일어납니다.

  3. OS 대기 · epoll_wait / kevent / WEPoll

    준비된 fd가 생기거나, 타임아웃이 지나거나, wakeup()이 신호 fd에 쓰기 전까지 스레드가 여기서 멈춥니다. 등록된 연결이 몇 개든 대기하는 스레드는 하나입니다.

  4. processDeregisterQueue() · 대기 중 취소된 키 정리

    대기하는 동안 다른 스레드가 cancel()한 키를 한 번 더 처리합니다.

  5. processEvents() · fd → 키 → selectedKeys

    fdToKey로 키를 찾아 위의 덮어쓰기/OR 규칙대로 readyOps를 기록합니다. wakeup 신호 fd였다면 신호를 비우기만 합니다.

  6. 반환 · 새로 추가되거나 readyOps가 바뀐 키 수

    0일 수도 있습니다. wakeup()으로 깨어났을 때가 대표적입니다.

  7. 호출자 몫 · selectedKeys 순회 → 처리 → it.remove()

    Selector는 selectedKeys를 비워 주지 않습니다. 비우는 일은 항상 애플리케이션 코드가 합니다.

준비 상태는 해소될 때까지 매번 다시 알려 준다

Java Selector는 레벨 트리거(level-triggered)처럼 동작합니다. "준비 상태가 바뀌었을 때"가 아니라 "지금 준비돼 있으면" 매번 키를 돌려줍니다. 송신 버퍼는 거의 항상 비어 있으므로 OP_WRITE는 켜 두기만 해도 거의 항상 준비 상태입니다.

NIO셀렉터 학습 노트의 그림 자료입니다. 자세한 설명과 실행 코드는 같은 폴더의 NIO셀렉터-이론.md, NIO셀렉터-예제.md에 있습니다.
