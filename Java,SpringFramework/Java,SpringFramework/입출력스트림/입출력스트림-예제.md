# 입출력 스트림 조합 — 예제

관련 문서: [이론](./입출력스트림-이론.md)

## 1. 예제 개요

`ByteArray*Stream`이 실제로 **언제 무엇을 주고받는지** 바이트 단위로 관찰한다. 출력 쪽은 "아직 안 내려갔다", 입력 쪽은 "끝을 모른다"를 재현한 뒤 고치고, JUnit으로 증명한다.

| 번호 | 예제 | 검증하는 개념 | 이론 문서 |
|---|---|---|---|
| [1] | 헤더 관찰 | 출력 생성자가 헤더 4바이트를 즉시 쓴다 | 3, 5.1 |
| [2] | `writeInt` 후 크기 | 원시값은 flush 전까지 블록 버퍼에 남는다 | 5.1, 8.1 |
| [3] | `BufferedOutputStream` 끼우기 | 체인 중간 버퍼가 객체 바이트도 막는다 | 5.3, 8.1 |
| [4] | `available()` 루프 | `ois.available()`은 객체를 세지 않는다, 끝은 `EOFException` | 5.2, 6, 8.2 |
| [5] | 조금씩 주는 입력 스트림 | `read(byte[])` 부분 읽기, `readFully` | 5.3, 8.3 |
| [6] | JSON 바이트를 역직렬화 | 입력 생성자가 헤더를 검증한다 | 5.2, 8.4 |
| [7] | 원본 배열 수정, `mark`/`reset` | `ByteArrayInputStream`은 배열을 공유한다 | 5.4, 6 |
| [8] | `ObjectOutputStream` 두 번 생성 | 헤더 중복 → `invalid type code: AC` | 6, 8.4 |
| [9] | 리스트 수정 후 재전송 | 양쪽 핸들 테이블, `reset()` | 6, 8.5 |
| [10] | 깊은 복사 | 올바른 왕복 패턴 | 8.1, 9 |

## 3. 잘못된 코드 먼저

### 3-1. [출력] 바깥 스트림을 닫지 않고 꺼내기

```java
ByteArrayOutputStream bos = new ByteArrayOutputStream();
ObjectOutputStream oos = new ObjectOutputStream(new BufferedOutputStream(bos));
oos.writeObject("hi");
byte[] bytes = bos.toByteArray();   // 길이 0
```

**문제**: 바이트가 `BufferedOutputStream`의 8192바이트 버퍼에 갇혀 있다. `bytes`는 빈 배열이고, 이걸 `new ObjectInputStream(...)`에 넣으면 헤더를 읽다가 `EOFException`이 난다. `BufferedOutputStream` 없이 `writeObject`만 쓰면 우연히 동작하기 때문에, "버퍼 하나 추가했더니 깨졌다"는 형태로 발견된다.

### 3-2. [입력] `available()`로 끝 판단

```java
ObjectInputStream ois = new ObjectInputStream(new ByteArrayInputStream(bytes));  // 객체 3개가 들어 있다
List<Object> result = new ArrayList<>();
while (ois.available() > 0) {       // 처음부터 0
    result.add(ois.readObject());
}
// result.size() == 0
```

**문제**: `ObjectInputStream#available()`은 블록 데이터(원시값) 안의 바이트만 센다. 다음이 객체면 0이다. 이 루프를 `readObject() != null`로 바꾸면 이번에는 마지막에 `EOFException`이 난다.

### 3-3. [입력] `read(byte[])` 반환값 무시

```java
byte[] buf = new byte[11];
in.read(buf);                        // "다 읽었겠지"
String s = new String(buf, StandardCharsets.US_ASCII);
```

**문제**: `read`는 1바이트 이상 `len`바이트 이하를 읽는다. `ByteArrayInputStream`으로 테스트하면 항상 11바이트가 채워져서 통과한다. 소켓이나 HTTP 본문에서는 3바이트만 채워지고 나머지는 0인 채로 진행된다.

### 3-4. [양쪽] 같은 `bos`에 `ObjectOutputStream`을 두 번 만들기

```java
ByteArrayOutputStream bos = new ByteArrayOutputStream();
new ObjectOutputStream(bos).writeObject("first");
new ObjectOutputStream(bos).writeObject("second");   // "이어 쓰기"

ObjectInputStream ois = new ObjectInputStream(new ByteArrayInputStream(bos.toByteArray()));
ois.readObject();   // "first"
ois.readObject();   // StreamCorruptedException: invalid type code: AC
```

**문제**: 두 번째 생성자가 헤더를 또 쓴다. 읽는 쪽은 헤더를 처음 한 번만 읽으므로 두 번째 `AC`를 타입 코드로 해석하다 실패한다.

### 3-5. [양쪽] 수정한 객체를 같은 스트림으로 다시 보내기

```java
List<String> cart = new ArrayList<>();
cart.add("apple");
oos.writeObject(cart);
cart.add("banana");
oos.writeObject(cart);   // 받는 쪽: 여전히 [apple], 첫 번째와 같은 인스턴스
```

**문제**: 쓰는 쪽 핸들 테이블이 참조 5바이트만 보내고, 읽는 쪽 핸들 테이블이 첫 번째 인스턴스를 그대로 돌려준다. 예외가 없어서 오래 숨어 있는 버그가 된다.

## 4. 개선된 코드

### 4-1. [출력] 닫은 뒤에 꺼낸다 (3-1 해결)

```java
ByteArrayOutputStream bos = new ByteArrayOutputStream();
try (ObjectOutputStream oos = new ObjectOutputStream(bos)) {
    oos.writeObject(obj);
}                                   // close → 체인 전체 flush
return bos.toByteArray();           // bos.close()는 no-op이라 닫힌 뒤에도 꺼낼 수 있다
```

**좋아진 점**: 중간에 `BufferedOutputStream`이나 `GZIPOutputStream`을 끼워도 결과가 같다.

### 4-2. [입력] 개수를 먼저 쓰고 그만큼 읽는다 (3-2 해결)

```java
// 쓰기
oos.writeInt(objects.size());
for (Object o : objects) {
    oos.writeObject(o);
}

// 읽기
int count = ois.readInt();
for (int i = 0; i < count; i++) {
    result.add(ois.readObject());
}
```

**좋아진 점**: 끝을 추측하지 않는다. 쓰는 쪽 형식을 바꿀 수 없다면 차선책으로 `EOFException`을 끝 신호로 잡는다(6장 [4] 두 번째 줄).

### 4-3. [입력] 요청한 길이를 보장하는 메서드를 쓴다 (3-3 해결)

```java
byte[] buf = new byte[11];
new DataInputStream(in).readFully(buf);   // 11바이트를 다 채우거나 EOFException
// Java 9+: in.readNBytes(buf, 0, buf.length)는 읽은 수를 돌려주고, 끝이면 덜 채울 수 있다 — 반환값 확인 필요
// Java 11+: byte[] buf = in.readNBytes(11);
```

**좋아진 점**: 끝점이 메모리든 네트워크든 같은 결과가 나온다. 테스트에서는 `TrickleInputStream`으로 감싸 네트워크 상황을 재현한다.

### 4-4. [양쪽] 하나의 스트림에 하나의 `ObjectOutputStream` (3-4 해결)

4-2처럼 하나의 `ObjectOutputStream`으로 여러 객체를 쓴다. 메시지를 정말 따로 저장해야 한다면 메시지마다 4-1로 독립된 `byte[]`를 만들어 따로 저장한다.

### 4-5. [양쪽] 다시 보내기 전에 `reset()` (3-5 해결)

```java
oos.writeObject(cart);
cart.add("banana");
oos.reset();              // 쓰는 쪽 표를 비우고 TC_RESET 기록 → 읽는 쪽 표도 비워진다
oos.writeObject(cart);    // 전체 내용이 다시 기록된다
```

**좋아진 점**: 수정된 내용이 전달되고, 장수명 연결에서는 양쪽 핸들 테이블에 쌓인 객체가 풀려 메모리 누수도 막는다.

## 5. 전체 코드

### `StreamBytes.java`

```java
package study.stream;

import java.io.ByteArrayInputStream;
import java.io.ByteArrayOutputStream;
import java.io.IOException;
import java.io.ObjectInputStream;
import java.io.ObjectOutputStream;
import java.io.Serializable;
import java.io.UncheckedIOException;
import java.util.ArrayList;
import java.util.List;

public final class StreamBytes {

    private StreamBytes() {
    }

    public static byte[] serialize(Object obj) {
        // try 밖에서 선언: 바깥 스트림을 닫은 "뒤에" 꺼내야 체인의 모든 버퍼가 비워진 상태가 보장된다
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        try (ObjectOutputStream oos = new ObjectOutputStream(bos)) {
            oos.writeObject(obj);
        } catch (IOException e) {
            // ByteArrayOutputStream은 I/O 실패가 없다. 여기 오는 건 NotSerializableException 같은 직렬화 실패다
            throw new UncheckedIOException(e);
        }
        return bos.toByteArray();
    }

    public static byte[] serializeAll(List<?> objects) {
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        try (ObjectOutputStream oos = new ObjectOutputStream(bos)) {
            // 헤더는 한 번만. 개수를 먼저 써서 읽는 쪽이 available()이나 EOF로 끝을 추측하지 않게 한다
            oos.writeInt(objects.size());
            for (Object o : objects) {
                oos.writeObject(o);
            }
        } catch (IOException e) {
            throw new UncheckedIOException(e);
        }
        return bos.toByteArray();
    }

    // 주의: 직접 만든 바이트에만 쓴다. 외부 입력을 역직렬화하면 원격 코드 실행 위험이 있다 (직렬화 이론 8.6)
    public static Object deserialize(byte[] bytes) {
        try (ObjectInputStream ois = new ObjectInputStream(new ByteArrayInputStream(bytes))) {
            return ois.readObject();
        } catch (IOException e) {
            throw new UncheckedIOException(e);
        } catch (ClassNotFoundException e) {
            throw new IllegalStateException(e);
        }
    }

    public static List<Object> deserializeAll(byte[] bytes) {
        try (ObjectInputStream ois = new ObjectInputStream(new ByteArrayInputStream(bytes))) {
            // 쓴 순서 그대로: int 먼저, 그다음 객체. 순서가 어긋나면 OptionalDataException
            int count = ois.readInt();
            List<Object> result = new ArrayList<>(count);
            for (int i = 0; i < count; i++) {
                result.add(ois.readObject());
            }
            return result;
        } catch (IOException e) {
            throw new UncheckedIOException(e);
        } catch (ClassNotFoundException e) {
            throw new IllegalStateException(e);
        }
    }

    @SuppressWarnings("unchecked")
    public static <T extends Serializable> T deepCopy(T obj) {
        return (T) deserialize(serialize(obj));
    }

    public static String hex(byte[] bytes) {
        StringBuilder sb = new StringBuilder();
        for (byte b : bytes) {
            if (sb.length() > 0) {
                sb.append(' ');
            }
            // & 0xFF: byte는 부호가 있어서 0xAC가 -84로 들어온다. int로 넓힐 때 부호 확장을 막는다
            sb.append(String.format("%02X", b & 0xFF));
        }
        return sb.toString();
    }
}
```

### `TrickleInputStream.java`

```java
package study.stream;

import java.io.FilterInputStream;
import java.io.IOException;
import java.io.InputStream;

/**
 * 한 번의 read 호출에 최대 maxChunk 바이트만 돌려주는 데코레이터.
 * 소켓·HTTP 본문처럼 "도착한 만큼만 주는" 끝점을 테스트에서 재현하려고 만든다.
 * ByteArrayInputStream은 항상 한 번에 다 주기 때문에 부분 읽기 버그를 숨긴다.
 */
public class TrickleInputStream extends FilterInputStream {

    private final int maxChunk;

    public TrickleInputStream(InputStream in, int maxChunk) {
        super(in);
        this.maxChunk = maxChunk;
    }

    @Override
    public int read(byte[] b, int off, int len) throws IOException {
        // FilterInputStream#read(byte[])는 이 메서드로 위임하므로 여기만 막으면 된다
        return super.read(b, off, Math.min(len, maxChunk));
    }
}
```

### `StreamDemo.java`

```java
package study.stream;

import java.io.BufferedOutputStream;
import java.io.ByteArrayInputStream;
import java.io.ByteArrayOutputStream;
import java.io.DataInputStream;
import java.io.EOFException;
import java.io.IOException;
import java.io.InputStream;
import java.io.ObjectInputStream;
import java.io.ObjectOutputStream;
import java.io.StreamCorruptedException;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

import static study.stream.StreamBytes.hex;

public class StreamDemo {

    public static void main(String[] args) throws Exception {
        // 출력
        headerDemo();
        blockDataDemo();
        bufferedDemo();
        // 입력
        availableDemo();
        partialReadDemo();
        invalidHeaderDemo();
        sharedArrayDemo();
        // 양쪽
        appendDemo();
        resetDemo();
        deepCopyDemo();
    }

    // [1] 생성자가 헤더를 즉시 쓰고, 최상위 writeObject 직후에는 바이트가 bos에 도착해 있다
    static void headerDemo() throws IOException {
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        try (ObjectOutputStream oos = new ObjectOutputStream(bos)) {
            System.out.println("[1] 생성 직후       size=" + bos.size() + "  " + hex(bos.toByteArray()));
            oos.writeObject("hi");
            System.out.println("[1] writeObject 후  size=" + bos.size() + "  " + hex(bos.toByteArray()));
        }
    }

    // [2] 원시값은 블록 버퍼에 남아 있다가 flush 때 TC_BLOCKDATA로 내려간다
    static void blockDataDemo() throws IOException {
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        try (ObjectOutputStream oos = new ObjectOutputStream(bos)) {
            oos.writeInt(42);
            System.out.println("[2] writeInt 후     size=" + bos.size());
            oos.flush();
            System.out.println("[2] flush 후        size=" + bos.size() + "  " + hex(bos.toByteArray()));
        }
    }

    // [3] 체인 중간의 BufferedOutputStream이 헤더와 객체 바이트를 모두 붙잡는다
    static void bufferedDemo() throws IOException {
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        try (ObjectOutputStream oos = new ObjectOutputStream(new BufferedOutputStream(bos))) {
            oos.writeObject("hi");
            System.out.println("[3] Buffered flush 전 size=" + bos.size());
            oos.flush();
            System.out.println("[3] Buffered flush 후 size=" + bos.size());
        }
    }

    // [4] ois.available()은 객체를 세지 않는다. 끝은 EOFException으로만 알 수 있다
    static void availableDemo() throws Exception {
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        try (ObjectOutputStream oos = new ObjectOutputStream(bos)) {
            oos.writeObject("a");
            oos.writeObject("b");
            oos.writeObject("c");
        }
        byte[] bytes = bos.toByteArray();

        int byAvailable = 0;
        try (ObjectInputStream ois = new ObjectInputStream(new ByteArrayInputStream(bytes))) {
            while (ois.available() > 0) {
                ois.readObject();
                byAvailable++;
            }
        }

        int byEof = 0;
        try (ObjectInputStream ois = new ObjectInputStream(new ByteArrayInputStream(bytes))) {
            while (true) {
                ois.readObject();
                byEof++;
            }
        } catch (EOFException endOfStream) {
            // 형식을 바꿀 수 없을 때의 차선책. 가능하면 개수를 먼저 쓴다 (StreamBytes#serializeAll)
        }
        System.out.println("[4] available 루프로 읽은 수 = " + byAvailable);
        System.out.println("[4] EOF까지 읽은 수 = " + byEof);
    }

    // [5] read(byte[])는 요청보다 적게 읽을 수 있다. readFully는 다 채운다
    static void partialReadDemo() throws IOException {
        byte[] data = "HELLO-WORLD".getBytes(StandardCharsets.US_ASCII);

        byte[] buf = new byte[data.length];
        InputStream network = new TrickleInputStream(new ByteArrayInputStream(data), 3);
        int n = network.read(buf);
        System.out.println("[5] read(byte[]) 반환값 = " + n + " / 요청 " + buf.length);

        byte[] full = new byte[data.length];
        new DataInputStream(new TrickleInputStream(new ByteArrayInputStream(data), 3)).readFully(full);
        System.out.println("[5] readFully 결과 = " + new String(full, StandardCharsets.US_ASCII));
    }

    // [6] ObjectInputStream 생성자는 헤더를 검증한다. 직렬화가 아닌 바이트는 생성 단계에서 거부된다
    static void invalidHeaderDemo() throws IOException {
        byte[] json = "{\"name\":\"kim\"}".getBytes(StandardCharsets.UTF_8);
        try {
            new ObjectInputStream(new ByteArrayInputStream(json));
        } catch (StreamCorruptedException e) {
            System.out.println("[6] " + e);
        }
    }

    // [7] ByteArrayInputStream은 배열을 복사하지 않는다. mark/reset으로 되감기도 가능하다
    static void sharedArrayDemo() {
        byte[] data = {1, 2, 3};
        ByteArrayInputStream bis = new ByteArrayInputStream(data);
        data[0] = 9;                       // 스트림을 만든 "뒤에" 원본을 수정

        int first = bis.read();            // 9 — 공유하고 있으므로 수정이 보인다
        bis.mark(0);                       // ByteArrayInputStream은 readlimit을 무시한다
        bis.read();                        // 2
        bis.read();                        // 3
        bis.reset();                       // mark 위치(인덱스 1)로 되감기
        int again = bis.read();            // 2
        System.out.println("[7] 원본 수정 후 첫 read = " + first + ", reset 후 read = " + again);
    }

    // [8] ObjectOutputStream을 두 번 만들면 헤더가 두 번 들어간다
    static void appendDemo() throws Exception {
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        try (ObjectOutputStream first = new ObjectOutputStream(bos)) {
            first.writeObject("first");
        }
        // bos.close()가 no-op이므로 닫힌 bos에 계속 쓸 수 있다 — 그래서 이 실수가 예외 없이 진행된다
        try (ObjectOutputStream second = new ObjectOutputStream(bos)) {
            second.writeObject("second");
        }
        System.out.println("[8] 이어 쓴 크기 = " + bos.size());

        try (ObjectInputStream ois = new ObjectInputStream(new ByteArrayInputStream(bos.toByteArray()))) {
            System.out.println("[8] 첫 번째 읽기 = " + ois.readObject());
            try {
                ois.readObject();
            } catch (StreamCorruptedException e) {
                System.out.println("[8] 두 번째 읽기 실패: " + e);
            }
        }
    }

    // [9] 핸들 테이블 때문에 수정이 전달되지 않고, reset() 후에는 전달된다
    static void resetDemo() throws Exception {
        List<String> cart = new ArrayList<>(Arrays.asList("apple"));
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        try (ObjectOutputStream oos = new ObjectOutputStream(bos)) {
            oos.writeObject(cart);
            cart.add("banana");
            oos.writeObject(cart);   // 참조만 기록됨
            oos.reset();
            oos.writeObject(cart);   // 전체 다시 기록됨
        }
        try (ObjectInputStream ois = new ObjectInputStream(new ByteArrayInputStream(bos.toByteArray()))) {
            Object a = ois.readObject();
            Object b = ois.readObject();
            Object c = ois.readObject();
            System.out.println("[9] a=" + a + " b=" + b + " c=" + c);
            System.out.println("[9] a==b " + (a == b) + ", a==c " + (a == c));
        }
    }

    // [10] 올바른 왕복으로 만든 깊은 복사
    static void deepCopyDemo() {
        Member original = new Member("kim", Arrays.asList("java"));
        Member copy = StreamBytes.deepCopy(original);
        copy.getTags().add("io");
        System.out.println("[10] 원본 tags=" + original.getTags() + " 복사본 tags=" + copy.getTags());
        System.out.println("[10] original==copy " + (original == copy)
                + ", tags 공유 " + (original.getTags() == copy.getTags()));
    }
}
```

## 7. 검증 코드

### `StreamChainTest.java`

```java
package study.stream;

import org.junit.jupiter.api.Test;

import java.io.BufferedOutputStream;
import java.io.ByteArrayInputStream;
import java.io.ByteArrayOutputStream;
import java.io.DataInputStream;
import java.io.EOFException;
import java.io.IOException;
import java.io.InputStream;
import java.io.ObjectInputStream;
import java.io.ObjectOutputStream;
import java.io.StreamCorruptedException;
import java.nio.charset.StandardCharsets;
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

import static org.assertj.core.api.Assertions.assertThat;
import static org.assertj.core.api.Assertions.assertThatThrownBy;

class StreamChainTest {

    // ---------- 출력 ----------

    @Test
    void 출력_생성자가_헤더_4바이트를_즉시_쓴다() throws IOException {
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        new ObjectOutputStream(bos);

        assertThat(bos.toByteArray())
                .containsExactly((byte) 0xAC, (byte) 0xED, (byte) 0x00, (byte) 0x05);
    }

    @Test
    void 원시값은_flush_전까지_bos에_보이지_않는다() throws IOException {
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        ObjectOutputStream oos = new ObjectOutputStream(bos);

        oos.writeInt(42);
        assertThat(bos.size()).isEqualTo(4);          // 헤더만

        oos.flush();
        assertThat(bos.size()).isEqualTo(4 + 2 + 4);  // 헤더 + 블록 헤더(77 04) + int
    }

    @Test
    void 중간_BufferedOutputStream은_close해야_비워진다() throws IOException {
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        ObjectOutputStream oos = new ObjectOutputStream(new BufferedOutputStream(bos));
        oos.writeObject("hi");

        assertThat(bos.size()).isZero();

        oos.close();
        assertThat(bos.size()).isEqualTo(9);
        assertThat(StreamBytes.deserialize(bos.toByteArray())).isEqualTo("hi");
    }

    @Test
    void toByteArray는_복사본이고_close_후에도_동작한다() throws IOException {
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        bos.write(new byte[]{1, 2, 3}, 0, 3);
        bos.close();                                  // no-op

        byte[] first = bos.toByteArray();
        first[0] = 99;

        assertThat(bos.toByteArray()).containsExactly(1, 2, 3);
        bos.write(4);                                 // 닫힌 뒤에도 쓸 수 있다
        assertThat(bos.size()).isEqualTo(4);
    }

    // ---------- 입력 ----------

    @Test
    void 입력_생성자가_헤더를_먼저_소비한다() throws IOException {
        byte[] bytes = StreamBytes.serialize("hi");   // 9바이트
        ByteArrayInputStream bis = new ByteArrayInputStream(bytes);

        new ObjectInputStream(bis);

        assertThat(bis.available()).isEqualTo(bytes.length - 4);
    }

    @Test
    void 입력_생성자는_직렬화가_아닌_바이트를_거부한다() {
        byte[] json = "{\"name\":\"kim\"}".getBytes(StandardCharsets.UTF_8);

        assertThatThrownBy(() -> new ObjectInputStream(new ByteArrayInputStream(json)))
                .isInstanceOf(StreamCorruptedException.class)
                .hasMessageContaining("7B226E61");    // 메시지 문구는 JDK 버전에 따라 다를 수 있다
    }

    @Test
    void 빈_바이트로_입력_스트림을_만들면_EOFException() {
        assertThatThrownBy(() -> new ObjectInputStream(new ByteArrayInputStream(new byte[0])))
                .isInstanceOf(EOFException.class);
    }

    @Test
    void ObjectInputStream의_available은_객체를_세지_않는다() throws Exception {
        byte[] bytes = StreamBytes.serialize("hi");

        try (ObjectInputStream ois = new ObjectInputStream(new ByteArrayInputStream(bytes))) {
            assertThat(ois.available()).isZero();     // 객체가 남아 있는데도 0
            assertThat(ois.readObject()).isEqualTo("hi");
        }
    }

    @Test
    void 끝에서_readObject는_null이_아니라_EOFException을_던진다() throws Exception {
        byte[] bytes = StreamBytes.serialize("only");

        try (ObjectInputStream ois = new ObjectInputStream(new ByteArrayInputStream(bytes))) {
            ois.readObject();
            assertThatThrownBy(ois::readObject).isInstanceOf(EOFException.class);
        }
    }

    @Test
    void 잘린_바이트는_EOFException() {
        byte[] bytes = StreamBytes.serialize("hi");
        byte[] truncated = Arrays.copyOf(bytes, 5);   // 헤더 + TC_STRING까지만

        assertThatThrownBy(() -> StreamBytes.deserialize(truncated))
                .hasCauseInstanceOf(EOFException.class);   // StreamBytes가 UncheckedIOException으로 감쌌다
    }

    @Test
    void 개수를_먼저_쓰면_정확히_읽힌다() {
        byte[] bytes = StreamBytes.serializeAll(Arrays.asList("first", "second", 3));

        assertThat(StreamBytes.deserializeAll(bytes)).containsExactly("first", "second", 3);
    }

    @Test
    void read는_요청보다_적게_읽을_수_있고_readFully는_다_채운다() throws IOException {
        byte[] data = "HELLO-WORLD".getBytes(StandardCharsets.US_ASCII);

        InputStream network = new TrickleInputStream(new ByteArrayInputStream(data), 3);
        assertThat(network.read(new byte[data.length])).isEqualTo(3);

        byte[] full = new byte[data.length];
        new DataInputStream(new TrickleInputStream(new ByteArrayInputStream(data), 3)).readFully(full);
        assertThat(full).isEqualTo(data);
    }

    @Test
    void ByteArrayInputStream은_배열을_복사하지_않는다() {
        byte[] data = {1, 2, 3};
        ByteArrayInputStream bis = new ByteArrayInputStream(data);

        data[0] = 9;

        assertThat(bis.read()).isEqualTo(9);
    }

    // ---------- 양쪽 ----------

    @Test
    void ObjectOutputStream을_두번_만들면_두번째_읽기가_실패한다() throws Exception {
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        try (ObjectOutputStream oos = new ObjectOutputStream(bos)) {
            oos.writeObject("first");
        }
        try (ObjectOutputStream oos = new ObjectOutputStream(bos)) {
            oos.writeObject("second");
        }

        try (ObjectInputStream ois = new ObjectInputStream(new ByteArrayInputStream(bos.toByteArray()))) {
            assertThat(ois.readObject()).isEqualTo("first");
            assertThatThrownBy(ois::readObject)
                    .isInstanceOf(StreamCorruptedException.class)
                    .hasMessageContaining("AC");
        }
    }

    @Test
    void 핸들_테이블_때문에_수정이_전달되지_않고_reset하면_전달된다() throws Exception {
        List<String> cart = new ArrayList<>(Arrays.asList("apple"));
        ByteArrayOutputStream bos = new ByteArrayOutputStream();
        try (ObjectOutputStream oos = new ObjectOutputStream(bos)) {
            oos.writeObject(cart);
            cart.add("banana");
            oos.writeObject(cart);
            oos.reset();
            oos.writeObject(cart);
        }

        try (ObjectInputStream ois = new ObjectInputStream(new ByteArrayInputStream(bos.toByteArray()))) {
            Object a = ois.readObject();
            Object b = ois.readObject();
            Object c = ois.readObject();

            assertThat(b).isSameAs(a);
            assertThat((List<?>) b).containsExactly("apple");
            assertThat(c).isNotSameAs(a);
            assertThat((List<?>) c).containsExactly("apple", "banana");
        }
    }

    @Test
    void 깊은_복사는_내부_리스트까지_분리한다() {
        Member original = new Member("kim", Arrays.asList("java"));
        Member copy = StreamBytes.deepCopy(original);

        copy.getTags().add("io");

        assertThat(copy).isNotSameAs(original);
        assertThat(copy.getTags()).isNotSameAs(original.getTags());
        assertThat(original.getTags()).containsExactly("java");
    }
}
```

- `containsExactly(1, 2, 3)`: AssertJ의 `byte[]` 단언은 `int...` 오버로드를 제공해서 캐스팅 없이 쓸 수 있다. `0x7F`보다 큰 값은 `(byte)` 캐스팅을 쓰는 편이 의도가 분명하다.
- `ObjectInputStream의_available은_객체를_세지_않는다`는 명세가 아니라 현재 JDK 구현 동작을 고정하는 테스트다. 명세가 보장하는 것은 "`available()`로 객체 개수를 판단할 수 없다"는 것까지다.

## 8. 변형 실습

### 실습 1. 쓴 순서와 다르게 읽으면?

`StreamBytes#deserializeAll`에서 `ois.readInt()`를 빼고 바로 `readObject()`부터 호출해 보자.
- 예상: `java.io.OptionalDataException`이 난다. 현재 위치에 블록 데이터(개수 int)가 남아 있는데 객체를 읽으려 했기 때문이다 (이론 5.2의 3-1단계).
- 교훈: 직렬화 스트림에는 "다음이 무엇인지"를 알려 주는 스키마가 없다. **쓰는 순서가 곧 프로토콜**이다.

### 실습 2. `TrickleInputStream` 위에서 역직렬화하면?

`new ObjectInputStream(new TrickleInputStream(new ByteArrayInputStream(StreamBytes.serialize(member)), 1))`로 한 번에 1바이트씩만 주면서 `readObject()`를 호출해 보자.
- 예상: 정상적으로 복원된다. `ObjectInputStream`은 내부에서 `readFully` 방식으로 필요한 만큼 반복해서 읽기 때문이다.
- 교훈: 부분 읽기(이론 8.3)는 **`read(byte[])`를 직접 호출하는 코드**의 문제다. 형식 읽기 메서드(`readInt`, `readObject`, `readFully`)에 맡기면 생기지 않는다.

### 실습 3. `GZIP`을 끼우고 `close()` 대신 `flush()`만 하면?

```java
ByteArrayOutputStream bos = new ByteArrayOutputStream();
ObjectOutputStream oos = new ObjectOutputStream(new GZIPOutputStream(bos));
oos.writeObject(new Member("kim", Arrays.asList("java")));
oos.flush();
byte[] bytes = bos.toByteArray();
new ObjectInputStream(new GZIPInputStream(new ByteArrayInputStream(bytes))).readObject();
```

- 예상: 읽는 쪽에서 `EOFException` 계열 예외가 난다. `GZIPOutputStream`은 `finish()`/`close()` 때 남은 압축 데이터와 트레일러(CRC, 길이)를 쓰므로, `flush()`만으로는 gzip 스트림이 완성되지 않는다. 정확한 예외 종류와 메시지는 확인이 필요하다.
- `oos.close()`로 바꾸면 정상 동작한다. 또 `GZIPInputStream`을 빼고 `ObjectInputStream`에 바로 넣으면 `invalid stream header: 1F8B0800`이 난다(이론 8.4). 쓰기와 읽기의 감싸는 순서가 **대칭**이어야 한다는 것을 확인할 수 있다.
